# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Narrative Engine, please **do not** open a public issue on GitHub.

Instead, please send an email directly to the project maintainer:
- **Contact:** Markus Marrei
- **Email:** `markus.marrei@gmail.com`

Please include:
- A detailed description of the vulnerability.
- Steps or a minimal reproducible example to recreate the issue.
- Potential impact and affected components.

We will review reports promptly and work on a resolution.
